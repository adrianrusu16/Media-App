# Complete overlayable resource catalog

The inventory below contains every `(type, name)` entry declared in `PandaWaveDesignTokens` exactly once. Values and source links are extracted from the current resource files. [CSV copy](resource-catalog.csv) supports filtering and OEM change sheets.

**Reading the tables:** `Provider` means the resource is loaded into the token model; this does not prove every token field has a visible consumer. `Direct code` means a production reference exists outside that provider. `XML chain` means resource-to-resource use was found; follow the link to check whether the chain reaches a visible surface. `Declared only` means no direct production reference was found in the inspected app/core/feature main sources. It remains an eligible target. Night `—` means no separate `values-night` definition, so the base entry applies unless an overlay/configuration supplies another value. Source links are pinned to the reviewed commit.

All resources currently use policy `public`. No overlayable strings, fonts, booleans, layouts, styles, arrays or mipmaps are declared in this group. Drawable XML roots and dimensions are summarized; follow their source links for complete paths and fills.

### 4.1 Selector state order

These are Android color-state-list declarations, not proof that Compose consumes them. State order is significant: the first matching entry wins. Within the supplied selectors, disabled comes before pressed, then focused, then selected/checked, then default.

| Selector resource | Ordered state → color / alpha |
| --- | --- |
| `pandawave_button_colors` | `enabled=false` → `on_surface` / `disabled_alpha`; `pressed=true` → `on_primary_container` / `pressed_alpha`; `focused=true` → `primary` / `focus_alpha`; `selected=true` → `on_primary` / `1`; `default` → `on_surface` / `1` |
| `pandawave_icon_button_colors` | `enabled=false` → `on_surface` / `disabled_alpha`; `pressed=true` → `on_primary_container` / `pressed_alpha`; `focused=true` → `primary` / `focus_alpha`; `selected=true` → `primary` / `1`; `default` → `on_surface_variant` / `1` |
| `pandawave_media_item_colors` | `enabled=false` → `on_surface` / `disabled_alpha`; `pressed=true` → `on_primary_container` / `pressed_alpha`; `focused=true` → `primary` / `focus_alpha`; `selected=true` → `primary` / `1`; `default` → `on_surface` / `1` |
| `pandawave_navigation_item_colors` | `enabled=false` → `on_surface` / `disabled_alpha`; `pressed=true` → `on_primary_container` / `pressed_alpha`; `focused=true` → `primary` / `focus_alpha`; `selected=true` → `primary` / `1`; `default` → `on_surface_variant` / `1` |
